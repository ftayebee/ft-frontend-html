Rowan Vale — Creative Developer Portfolio

Thank you for purchasing this template! A premium, multi-page HTML portfolio for developers, designers, freelancers and creative professionals — built with semantic HTML5, modern CSS and a little vanilla JavaScript. No frameworks, no build step.

Zero dependencies. No Bootstrap, jQuery, React or animation libraries. Just open the HTML files — everything works.

2. Template features

  • 9 HTML pages: Home, About, Services, Service Single, Portfolio, Project Single, Contact, Style Guide, 404.
  • Fully responsive (320px → 1920px), mobile-first.
  • One-file theming via CSS custom properties + 5 ready palettes.
  • Optional appearance customizer (accent, corners, text size, effects) with dark/light toggle.
  • Accessible: semantic landmarks, keyboard nav, focus states, ARIA, reduced-motion support.
  • Custom cursor, scroll reveals, marquee, accordion, portfolio filter — all degrade gracefully.
  • SEO metadata + JSON-LD structured data on every page.

Each page links a single stylesheet — assets/css/style.css — which @imports the modular CSS layers. Scripts load with defer and each self-initialises only if its markup is present.

4. How to open the template

Double-click any .html file to open it in your browser — it works straight from the file system. For the smoothest experience (and correct relative paths) run a tiny local server from the project folder:

# Python (any OS)
python -m http.server 8080
# then visit http://localhost:8080

# or Node
npx serve .

5. How to change colors

Open assets/css/variables.css. The primary accent is two variables near the top:

--color-primary: #9ee86f;        /* main accent */
--color-primary-strong: #73cf45; /* darker shade for gradients */

Change these to your brand color and the whole site updates. The file also includes 5 alternate palettes (Lime, Purple, Cyan, Orange, Monochrome) in comments — copy one into :root to use it as the default. Backgrounds, surfaces, text and borders are all variables in the same file.

Visitors can also switch the accent live via the on-page customizer panel (the gear button on the right edge). Their choice is saved in localStorage.

6. How to change fonts

Two families are used: Space Grotesk (display) and Inter (body). To swap them:

  1. Update the Google Fonts <link> in each page's <head> (or self-host).
  2. Update --font-display and --font-body in variables.css.

7. How to replace the logo

The logo is an inline SVG mark plus the wordmark Rowan. in the header and footer. Search the HTML for class="brand" and edit the <span class="brand__name"> text. To change the mark, edit the inline <svg class="brand__mark"> or replace assets/icons/favicon.svg. Update the favicon <link> tags too.

8. How to replace images

Demo images live in assets/images/ (portraits, portfolio/ covers, avatars). Replace a file or update the src. Always keep the width and height attributes (they prevent layout shift) and write meaningful alt text.

Optimize before shipping. Large photos slow your site. Export at the size you display and compress (TinyPNG, Squoosh, or WebP/AVIF). The hero image is intentionally not lazy-loaded; below-the-fold images use loading="lazy".

9. How to edit navigation

The header and mobile drawer are repeated on each page. Edit the .primary-nav__list and .mobile-drawer__list items. Mark the current page's link with aria-current="page" (already set per page).

Tip: the dev-only assets/partials/ folder contains the shared header/footer (_head.html, _foot.html) and a generator (build-pages.sh) if you prefer editing chrome in one place and regenerating.

10. How to add services

In services.html / index.html, copy a <article class="service-card"> block. Change the icon (<use href="#i-…">), the number, title, description and link. Add service-card--wide or service-card--feature for larger bento tiles.

11. How to add portfolio items

In portfolio.html, copy a <a class="project-card"> block inside .project-grid. Set its image, title, year and — important for filtering — the data-category attribute (space-separated for multiple categories).

12. How portfolio filtering works

Filter buttons carry data-filter="key"; cards carry data-category="key". portfolio-filter.js shows/hides cards by toggling .is-hidden and updates aria-pressed. Without JavaScript, all projects remain visible — nothing is hidden, so the page stays usable. The "Load more" button reveals a hidden [data-load-more-target] group.

13. How to configure the cursor

The custom cursor (dot + ring) is an enhancement. It auto-disables on touch devices and when reduce motion is set. To turn it off globally, open assets/js/cursor.js and set:

var ENABLE_CURSOR = false;

Or remove the .cursor-dot / .cursor-ring markup, or toggle it from the customizer panel. The native cursor is the fallback. Add data-cursor="view" to any element to show the "View" label on hover.

14. How to disable animations

Toggle "Scroll animations" off in the customizer (adds .no-anim to <html>), or remove the reveal-* classes from markup. The template fully honours the OS prefers-reduced-motion setting automatically. Content is never permanently hidden — if JS is disabled, everything still shows (a .no-js fallback).

15. How to configure dark / light mode

Dark is the primary design. The header/customizer toggle switches to light by setting data-theme="light" on <html> (see the light palette in variables.css). The choice persists via localStorage and theme-init.js applies it before first paint to avoid flashing. On a first visit the OS prefers-color-scheme is respected. To remove the feature entirely, delete the theme toggle buttons and theme-switcher.js.

16. How to connect the contact form

The contact & newsletter forms are front-end demos. They validate and show success/error UI but do not send anything. You must connect a backend.

Easiest options (no server code):

  • Formspree: set action="https://formspree.io/f/your-id" on the <form>, remove the data-demo-form attribute, and delete the e.preventDefault() behaviour in form.js (or remove the script).
  • Netlify Forms: add netlify to the <form> tag and deploy to Netlify.
  • Your own API: POST the form data to your endpoint with fetch() inside form.js.

17. How to update SEO metadata

Each page's <head> contains the <title>, meta description, canonical URL, Open Graph and Twitter tags, and JSON-LD structured data. Replace https://your-domain.com placeholders, the OG image path, and the Person/ProfessionalService details with your own.

18. How to deploy to shared hosting

This is a static site. Upload the project files (the HTML files and the assets/ folder) to your host's public folder (e.g. public_html) via FTP or the host's file manager. No database, Node, or build step is required. It also works on Netlify, Vercel, GitHub Pages, Cloudflare Pages — just point them at the folder.

20. Browser compatibility

Tested on the latest Chrome, Firefox, Edge and Safari (desktop + mobile). Requires a modern browser supporting CSS custom properties, grid and color-mix() (all evergreen browsers from ~2023 onward).
