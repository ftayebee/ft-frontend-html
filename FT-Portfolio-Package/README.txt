 ROWAN VALE — Creative Developer Portfolio Template  ·  v1.0.0
================================================================================

Thanks for your purchase! This is a static HTML/CSS/JS template — no build step,
no frameworks. Open any .html file in a browser to start.

QUICK START
-----------
1. Open index.html (double-click, or run a local server — see docs).
2. Read the full guide: documentation/index.html
3. Change your brand color in assets/css/variables.css (--color-primary).
4. Replace demo text, images and links with your own.
5. Connect the contact form to a backend (documentation §16).

PAGES
-----
index · about · services · service-single · portfolio · project-single ·
contact · style-guide · 404

WHERE THINGS LIVE
-----------------
assets/css/   — design system (edit variables.css first)
assets/js/    — vanilla JS modules (no dependencies)
assets/images — replace demo images here (optimize before publishing!)
documentation/index.html — full documentation (22 topics)
Licensing/asset-credits.txt — credits & image-licensing notice

DEVELOPER NOTES
---------------
• assets/partials/ holds the shared header/footer and a generator
  (build-pages.sh) used to keep chrome consistent. DEV ONLY — not needed to
  run the site. Run `bash assets/partials/make-package.sh` to build the clean
  delivery package (FT-Portfolio-Package/).
• assets/_originals/ holds full-resolution backups of optimized images. DEV ONLY.

IMPORTANT
---------
The demo photographs and the contact/newsletter forms are placeholders/demos.
Replace images with licensed assets and wire the form to a backend before
going live. See the documentation.
